# Previous submission analyses

This folder contains analyses and figure-generation code from the first submitted version of the manuscript. These materials are retained for transparency and record keeping but are not part of the current revised analysis.

Contents:
- `phylogenetic_trees/` — phylogenetic-tree code from the original submission.
- `tree_comparison_tanglegram/` — 16S/FastAAI tree-comparison and tanglegram workflow from the original submission.
- `venn/` — Venn/threshold-overlap workflow from the original submission.
